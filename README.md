# Rick and Morty Characters

This is a **pet project** created for studying and practicing the **Clean Swift (VIP)** architecture pattern in iOS development.

## 📱 Features

- 🧠 **Clean Swift Architecture (VIP)** — The project uses the Clean Swift (VIP) pattern to enforce modular design and clear separation of responsibilities.
- 📄 **Character List Screen** — Displays a list of characters from the [Rick and Morty API](https://rickandmortyapi.com/).
- 🔍 **Character Detail Screen** — Tapping on a character navigates to a screen with detailed information.
- 🔁 **Pagination Support** — Implements paginated API requests with infinite scroll behavior.
- 💾 **Core Data Integration** — Characters are persisted locally for offline support.
- 🖼 **Image Caching with Kingfisher** — Efficient asynchronous image loading and caching using [Kingfisher](https://github.com/onevcat/Kingfisher).

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/rick-and-morty-clean-swift.git
   cd rick-and-morty-clean-swift
   ```
2. Open the project in Xcode:
  ```bash
  open RickAndMorty.xcodeproj
  ```
3. Build and run on a simulator or physical device.
